================================================================================
INNOVATION HUB LAB MANAGEMENT SYSTEM - COMPLETE SETUP GUIDE
================================================================================

This guide will walk you through setting up and running the entire system
step-by-step on Windows.

================================================================================
STEP 1: VERIFY PYTHON INSTALLATION
================================================================================

1. Open PowerShell or Command Prompt
2. Check Python version:
   python --version
   
   You should see Python 3.11+ (you have 3.14 which is fine)

3. Check pip installation:
   pip --version

================================================================================
STEP 2: CREATE REQUIRED DIRECTORIES
================================================================================

The application needs specific folders to store the database, files, and photos.

In your project folder (E:\innovation\tst-lab-management-system-setup-14750\innovation-hub-lab),
run these commands in PowerShell:

New-Item -ItemType Directory -Force -Path instance
New-Item -ItemType Directory -Force -Path data
New-Item -ItemType Directory -Force -Path storage
New-Item -ItemType Directory -Force -Path storage\photos

OR manually create these folders:
- instance
- data
- storage
- storage\photos

================================================================================
STEP 3: CREATE VIRTUAL ENVIRONMENT (RECOMMENDED)
================================================================================

A virtual environment keeps dependencies isolated.

1. Create virtual environment:
   python -m venv venv

2. Activate it:
   .\venv\Scripts\activate

   You should see (venv) in your command prompt.

================================================================================
STEP 4: INSTALL DEPENDENCIES
================================================================================

1. Make sure you're in the project folder:
   cd E:\innovation\tst-lab-management-system-setup-14750\innovation-hub-lab

2. Install all required packages:
   pip install -r requirements.txt

   This installs:
   - Flask
   - Flask-SQLAlchemy
   - Flask-Login
   - openpyxl
   - requests
   - APScheduler
   - python-dotenv
   - werkzeug
   - And other dependencies

================================================================================
STEP 5: CREATE ENVIRONMENT FILE (.env)
================================================================================

1. Create a file named ".env" in the project root folder
   (same level as run.py)

2. Add this content to .env:

FLASK_APP=run.py
FLASK_ENV=development
SECRET_KEY=your-super-secret-key-change-this-in-production
DATABASE_URL=sqlite:///instance/app.db
EXCEL_FILE_PATH=data/responses.xlsx
ADMIN_DEFAULT_PASSWORD=Admin123!
PHOTO_RETENTION_DAYS=30
PHOTO_DELETION_HOUR=2
ESP_TIMEOUT_SECONDS=10
ESP_RETRY_COUNT=3
MAX_CONTENT_LENGTH=16777216

Note: Change SECRET_KEY and ADMIN_DEFAULT_PASSWORD for production!

================================================================================
STEP 6: INITIALIZE THE DATABASE
================================================================================

IMPORTANT: Do NOT use "flask db init" (that's for Flask-Migrate which we're not using).
We use db.create_all() which runs automatically.

1. Just run the app once to create all tables:
   python run.py

   The first run will:
   - Create all database tables
   - Initialize default settings
   - Create admin user if it doesn't exist

2. You should see:
   - "Database initialized successfully"
   - "Admin user created" (if first time)
   - " * Running on http://127.0.0.1:5000"

3. Press Ctrl+C to stop the server after you see these messages.

================================================================================
STEP 7: SEED DEMO DATA (OPTIONAL BUT RECOMMENDED)
================================================================================

This creates sample users, resources, and devices for testing.

1. Run the seed command:
   flask seed-demo

   This creates:
   - Admin user (username: admin, password: from .env or "Admin123!")
   - Engineer user (username: engineer, password: "Engineer123!")
   - Manager user (username: manager, password: "Manager123!")

================================================================================
STEP 8: PREPARE SAMPLE EXCEL FILE
================================================================================

1. Create a sample Excel file at: data/sample_responses.xlsx

2. The Excel file should have these columns (first row = headers):
   - ID (or Response ID)
   - Timestamp
   - Email
   - Full name
   - University ID
   - Phone / WhatsApp
   - Role
   - Request type
   - [Branch-specific columns based on request type]

3. Example request types in the "Request type" column:
   - workbench
   - tool_loan
   - hand_tools
   - staff_other
   - complaint
   - print_job

4. Update your .env if needed:
   EXCEL_FILE_PATH=data/sample_responses.xlsx

================================================================================
STEP 9: START THE APPLICATION
================================================================================

1. Make sure virtual environment is activated:
   .\venv\Scripts\activate

2. Run the application:
   python run.py

3. You should see:
   [2026-XX-XX XX:XX:XX] INFO in __init__: Innovation Hub Lab Management System starting...
   [2026-XX-XX XX:XX:XX] INFO in __init__: Database initialized successfully
   [2026-XX-XX XX:XX:XX] INFO in __init__: Starting photo retention scheduler...
   * Running on http://127.0.0.1:5000
   * Restarting with stat...

4. Keep this window open - the server is now running!

================================================================================
STEP 14: MOBILE ACCESS (FOR CAMERA FEATURE)
================================================================================

To use camera on mobile:

OPTION A - Same WiFi Network (Easiest for testing):
1. Find your computer's IP address:
   - Run: ipconfig
   - Look for IPv4 Address (e.g., 192.168.1.100)

2. On mobile, connect to same WiFi

3. On mobile browser, go to:
   http://192.168.1.100:5000

4. Note: Camera may not work on HTTP. See Option B.

OPTION B - Enable HTTPS (Required for camera):
1. Generate self-signed certificate:
   openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes

2. Run Flask with SSL:
   flask run --cert=cert.pem --key=key.pem --host=0.0.0.0

3. On mobile, go to:
   https://192.168.1.100:5000

4. Accept the security warning in your mobile browser

5. Camera will now work!

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "unable to open database file"
SOLUTION: 
- Make sure 'instance' folder exists
- Check folder permissions
- Close any other programs using the database

PROBLEM: "ModuleNotFoundError"
SOLUTION:
- Make sure virtual environment is activated
- Run: pip install -r requirements.txt

PROBLEM: Excel import fails
SOLUTION:
- Check EXCEL_FILE_PATH in settings matches actual file location
- Ensure Excel file is not open in another program
- Verify column names match expected names

PROBLEM: Camera doesn't work on mobile
SOLUTION:
- Must use HTTPS (not HTTP)
- Generate SSL certificate (see Step 14)
- Accept security warning in mobile browser

PROBLEM: Device commands fail
SOLUTION:
- Check device endpoint URL is correct
- Verify ESP32 device is online
- Check timeout settings (increase if needed)
- Review device command logs for error details

PROBLEM: Photos not uploading
SOLUTION:
- Check max file size in settings
- Verify storage/photos folder exists
- Check folder write permissions

================================================================================
IMPORTANT SECURITY NOTES
================================================================================

1. CHANGE DEFAULT PASSWORDS immediately after first login!

2. For production:
   - Use strong SECRET_KEY in .env
   - Enable HTTPS with proper SSL certificate
   - Don't expose port 5000 directly to internet
   - Use reverse proxy (Nginx/Apache)
   - Set FLASK_ENV=production

3. Regular backups:
   - Database: instance/app.db
   - Photos: storage/photos
   - Configuration: .env file

4. User management:
   - Only create necessary users
   - Assign minimum required roles
   - Deactivate unused accounts
